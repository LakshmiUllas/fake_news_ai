# TruthLens AI – Fake News Detection System

## Overview

TruthLens AI is a machine learning-powered web application designed to identify and classify news articles as either real or fake. The project leverages Natural Language Processing (NLP) techniques and supervised machine learning algorithms to analyze textual content and determine its credibility. By processing news headlines and article content, the system provides users with an instant prediction along with a confidence score, helping them assess the reliability of information found online.

## Features

* Real-time fake news detection through a user-friendly web interface
* Machine learning-based classification of news content
* Natural Language Processing (NLP) for text preprocessing and feature extraction
* Confidence score indicating prediction certainty
* Responsive and modern web design
* Easy deployment and scalability
* Trained using large-scale real and fake news datasets

## Technologies Used

## How It Works

The system processes news text submitted by the user and applies text-cleaning techniques such as tokenization and stop-word removal. The cleaned text is transformed into numerical features using TF-IDF vectorization. These features are then analyzed by a trained machine learning model, which predicts whether the content is real or fake. The final prediction and confidence score are displayed through the web interface.

## Project Goals

The primary goal of TruthLens AI is to combat misinformation by providing an accessible tool for evaluating the credibility of online news content. The project demonstrates the practical application of machine learning and NLP techniques in solving real-world challenges related to information authenticity.
